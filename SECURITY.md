# Security reporting

For a suspected vulnerability, use this repository's **Security > Report a
vulnerability** action. Do not include exploit details, credentials, or
customer data in a public issue.

If private reporting is unavailable, use your existing private Instantiations
support channel and identify the report as a VAST-MCP security issue.

Include the affected VAST-MCP version, VAST build, transport, authentication
configuration, impact, and a minimal sanitized reproduction. State whether a
remote caller, local process, or authenticated principal is required.

Release-specific security support commitments are not defined by this starter.
Report issues in any version and include whether the current release is affected.
